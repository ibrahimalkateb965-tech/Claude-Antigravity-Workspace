# خطة تنفيذ ميزة النشر التلقائي للتقارير على GitHub Pages

بناءً على طلبك بخصوص استعادة وتفعيل ميزة تصدير مستندات العمل (مثل `implementation_plan.md` و `walkthrough.md`) إلى صفحة GitHub، قمت بإعداد هذا المقترح الهندسي لإصلاح الميزة وأتمتتها بالكامل داخل بيئة العمل الحالية.

## مراجعة المستخدم (User Review Required)
> [!IMPORTANT]
> **مكان الاستضافة:** الخطة الحالية تقترح إنشاء مجلد باسم `docs/` داخل المستودع الحالي (`Claude+Antigravity -production`). على GitHub، يمكن بسهولة تفعيل ميزة "GitHub Pages" لتشير إلى هذا المجلد، مما يوفر رابطاً مباشراً لاستعراض التقارير. هل توافق على استخدام مجلد `docs/` في هذا المستودع، أم تفضل مستودعاً منفصلاً تماماً؟

## التغييرات المقترحة (Proposed Changes)

---

### [NEW] أداة المزامنة والنشر (Artifact Sync Tool)

#### [NEW] [sync_artifacts_to_github.py](file:///f:/AI%20PROJECTS/Claude+Antigravity%20-production/01_Agent_Computer_Interface_ACI/sync_artifacts_to_github.py)
سيتم بناء أداة بايثون ذكية تقوم بالتالي:
1. **استخراج أحدث التقارير:** البحث التلقائي في مجلد العقل الخاص بالمحرر (`<appDataDir>\brain`) عن أحدث المستندات والتقارير (Artifacts) التي تم إنشاؤها في المحادثات الحالية.
2. **تجهيز العرض:** نسخ هذه الملفات إلى مجلد `docs/` في مشروعنا، وإنشاء ملف `.nojekyll` (لمنع محرك Jekyll من حجب الملفات الخاصة)، بالإضافة لإنشاء فهرس تلقائي `index.md` يعرض قائمة بروابط لجميع التقارير.
3. **الرفع التلقائي (Git Push):** إضافة التعديلات للـ Git (Add)، عمل التزام (Commit)، ورفعها تلقائياً (Push) إلى مستودع المشروع على GitHub.

### [NEW] مجلد التوثيق العام (Docs Directory)
سيتم إنشاء مجلد `docs/` كحاوية لصفحة GitHub Pages لتخزين التقارير المنسوخة، وتجهيزه بملف التكوين الأساسي.

### [NEW] خطاف التفعيل (System Hook)
سنقوم بإضافة أو تعديل خطاف (Hook) في مكتبة الخطافات (Prompt Library)، ليتم تشغيل السكربت بمجرد أن تكتب أمراً مثل *"انشر التقارير"* أو *"Publish Artifacts"*.
