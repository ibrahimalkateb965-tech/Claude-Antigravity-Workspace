# 02 - خط أنابيب الوكلاء المتعددين (Multi-Agent ChatDev Pipeline)

## الفكرة والمفهوم:
إنشاء حلقة عمل وتعاون تسلسلية بين عدة وكلاء فرعيين (مثل المبرمج والمراجع والمختبر)؛ بحيث يمر الكود المكتوب عبر وكيل المراجعة لتدقيقه تلقائياً وتصحيحه قبل تسليمه للوكيل الرئيسي أو تقديمه للمستخدم.

## الهيكل المقترح للبناء:
- `agents/`: إعدادات الوكلاء المساهمين (Programmer, Reviewer, Tester).
- `protocols/`: بروتوكول نقل البيانات وصيغ الرسائل المتبادلة.
- `README.md`: دورة حياة المهمة البرمجية داخل خط الإنتاج.
