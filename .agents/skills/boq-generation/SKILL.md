# مهارة توليد جداول الكميات (BOQ Generation Skill)

## الأهداف
أتمتة بناء جداول الكميات وتفصيل البنود وحساب التكاليف الإفرادية والإجمالية وإدراج معادلات الضرائب تلقائياً.

## سير العمل الفني

1. **استخراج البنود:**
   - قراءة مواصفات المشروع وبنود كراسة الشروط.
   - تحديد الوحدات القياسية (م.ط، م2، م3، عدد، طن، مقطوعية).

2. **تحليل الأسعار:**
   - حساب تكلفة المواد الأساسية + المصنعية + النقل + الهوامش والأرباح.
   - كتابة المبالغ والكميات بالأرقام والحروف (توفير عمود الكمية كتابة لمنع التلاعب).

3. **حساب الضريبة:**
   - إدراج ضريبة القيمة المضافة بنسبة 15% في الخلاصة النهائية.

4. **توليد الملف:**
   - استدعاء سكريبت `generate_boq.py`.
   - التنسيق: خط Traditional Arabic، ترويسات ملونة، حدود خلايا واضحة، وتنسيق الأرقام لعرض خانتين عشريتين مع فواصل الآلاف.

## تعليمات الوكيل

- تحقق من تطابق الإجماليات دائماً باستخدام صيغ Excel (Formulas) مثل `=SUM()` و `=D4*E4` بدلاً من القيم الثابتة لسهولة التعديل اللاحق.
- التزم بتنسيق RTL للجدول بالكامل.
