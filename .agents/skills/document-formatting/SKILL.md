# مهارة تنسيق المستندات والإخراج النهائي (Document Formatting Skill)

## الأهداف
تطبيق القواعد الفنية والجمالية لضمان خروج كافة التقارير والخطابات والمنهجيات بمظهر احترافي وموحد يليق بمؤسسة إعمار الفرعة.

## القواعد الفنية الملزمة

1. **اتجاه النصوص:**
   - تفعيل اتجاه RTL (من اليمين إلى اليسار) لجميع النصوص والفقرات والجداول.

2. **الخطوط المعتمدة:**
   - خطوط عربية واضحة مثل `Traditional Arabic` أو `Sakkal Majalla` أو `Inter` للعناوين.
   - حجم الخط: 14pt للنصوص العادية، 16pt للعناوين الفرعية (Bold)، و 20pt للعناوين الرئيسية.

3. **الهوامش:**
   - ضبط الهوامش لجميع الاتجاهات بمقدار 2.5 سم (0.98 بوصة) لتسهيل الطباعة والتغليف.

4. **الجداول:**
   - محاذاة الجداول بالمنتصف.
   - رأس الجدول بلون أزرق داكن (`1F497D`) والخط باللون الأبيض.
   - حشو الخلايا (Padding) لعدم التصاق النصوص بالحدود.

5. **التحويل إلى PDF:**
   - استخدام مكتبات تحويل ذات جودة عالية لضمان بقاء الخطوط العربية مدمجة وصحيحة وبدون تقطيع أو قلب للحروف.

## سير العمل

- استدعاء سكريبت `format_docx.py` لتدقيق التنسيق بعد إنتاج أي ملف Word.
