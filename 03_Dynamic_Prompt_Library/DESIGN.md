# DESIGN.md — نظام التصميم المعتمد لتطبيق مكتبة الأوامر الذكية (Dynamic Prompt Library)

> **وثيقة التصميم المحلية لمشروع مكتبة الأوامر التفاعلية**
> مطابقة لمواصفات Google Stitch ونمط المطورين الداكن (Linear Dark) وباليت Vercel من مكتبة Refero Styles.
> تلتزم بتوأمة الخطوط العربية (Cairo + Tajawal + Fira Code) والتحصين الكامل ضد ركاكة الذكاء الاصطناعي (Anti-AI-Slop).

---

## 1. الهوية والمعمارية البصرية (Visual Architecture)

* **الهدف التشغيلي:** لوحة تحكم واستعراض فائقة السرعة للخطافات والأوامر البرمجية مع إمكانية النسخ بنقرة واحدة والبحث اللحظي.
* **النمط المستهدف:** نمط Linear المطورين الداكن المدمج مع لوحة Vercel المونوكرومية والنيلية الكهربائية.
* **العمق البصري:** خلفية سوداء سديمية (`#08090e`) تتضمن إضاءات محيطية خافتة (Ambient Gradient Meshes) غير مشتتة للنظر، وبطاقات بأسطح شفافة معتمدة على التمويه الزجاجي (`backdrop-filter: blur(20px)`).

## 3. معايير المكونات وتطهير السلوك (Component Guidelines)

1. **الزر الرئيسي الأوحد (Single Primary CTA):**
   * زر "رفع ملف جديد" (`.btn-upload`) هو الزر الممتلئ المتدرج الوحيد في شريط التحكم.
   * أزرار التبويبات وأزرار النسخ تكون بنمط شفاف/خطي (`Ghost/Outline`) وتبرز فقط عند التفاعل أو التفعيل.
2. **شريط البحث والتحكم (Sticky Control Panel):**
   * تثبيت سلس في أعلى الشاشة بخلفية زجاجية مصنفرة (`blur: 24px`) لمنع حجب الرؤية أثناء التمرير.
   * إبراز حقل البحث عند التركيز مع حلقة نيلية (`rgba(99, 102, 241, 0.2)`).
3. **بطاقة الأمر (Prompt Card):**
   * خط علوي خفيف يتدرج عند التحويم لإعطاء شعور بالاستجابة الحية.
   * زر النسخ يظهر أيقونة النجاح الخضراء (`fa-check`) مع تأثير لمسي فوري.
   * حقل الأمر البرمجي محاط بحد رمزي داكن مع خط `Fira Code` ومحاذاة أفقية متكيفة.
