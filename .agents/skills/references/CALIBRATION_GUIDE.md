# دليل ضبط المراجع الهندسية

## ما هو نظام المراجع؟

نظام بسيط يتيح لك **أنت** تحديد الملفات النموذجية التي يجب أن يلتزم النظام بهيكلها وتنسيقها عند إنتاج مستندات جديدة.

بدلاً من أن يخمّن النظام كيف تريد المخرجات — **أنت تعطيه النموذج المثالي وهو يلتزم به**.

---

## الطريقة الأولى: ضبط يدوي (أنت تقوم بذلك)

### الخطوات:

#### 1. انسخ الملف النموذجي
انسخ الملف الذي تعتبره نموذجاً مثالياً إلى المجلد المناسب:

```
g:\M.Yonis\.agents\skills\references\
├── جداول_زمنية\      ← ملفات Excel للجداول الزمنية وجداول الأنشطة
├── منهجيات\          ← ملفات Word لمنهجيات إنجاز الأعمال
├── جداول_كميات\      ← ملفات Excel لجداول الكميات والمقايسات
├── خطابات\           ← ملفات Word/PDF للمراسلات الرسمية
└── تقارير\           ← ملفات التقارير والمحاضر والمستخلصات
```

**مثال عملي:**
لو تريد أن يلتزم النظام بنفس شكل جدول الأنشطة الذي أنتجته لمشروع حديقة الملك فهد:
```
انسخ: g:\M.Yonis\حديقة الملك فهد الحلوة\A-14-Activities.xlsx
إلى:  g:\M.Yonis\.agents\skills\references\جداول_زمنية\A-14-Activities.xlsx
```

#### 2. سجّل الملف في الفهرس
افتح ملف الفهرس:
```
g:\M.Yonis\.agents\skills\references\index.md
```

وأضف سطراً في الجدول المناسب:

```markdown
| 1 | A-14-Activities.xlsx | قالب جدول الأنشطة المعتمد — أعمدة: WBS, النشاط, المدة, البداية, النهاية, السابق | [بطاقة](cards/A-14-Activities.md) | استخدمه لكل مشروع جديد |
```

#### 3. اكتمل الضبط
في المرة القادمة التي تطلب فيها جدول أنشطة، سيقرأ النظام الفهرس ثم يقرأ الملف النموذجي ويلتزم بنفس الهيكل.

---

## الطريقة الثانية: ضبط بمساعدة الوكيل (الموصى بها)

### كيف تعمل؟

بدلاً من أن تنسخ وتسجّل يدوياً، تطلب من الوكيل `reference-calibrator` وهو يقوم بكل شيء:

### الأوامر المحفّزة:

| ما تكتبه | ما يحدث |
|:---|:---|
| `ضبط مرجع` | يسألك عن مسار الملف وتصنيفه ويبدأ التحليل |
| `أضف مرجع: [مسار الملف]` | يحلل الملف مباشرة ويصنفه |
| `هذا الملف نموذج` | يأخذ الملف المفتوح حالياً كمرجع |
| `حلل هذا الملف واستخرج هيكله` | يقرأ الملف ويستخرج الأنماط والهيكل |

### مثال عملي:

**أنت تكتب:**
```
ضبط مرجع: g:\M.Yonis\كوبري السلامية بالحوطة\منهجية انجاز الأعمال.docx
التصنيف: منهجية
ملاحظة: هذا أفضل نموذج لمنهجيات مشاريع الإنشاء
```

**الوكيل يقوم بـ:**
1. ✅ قراءة الملف وتحليل هيكله (العناوين، الأقسام، الجداول، التنسيقات)
2. ✅ إنشاء بطاقة تفصيلية في `cards/منهجية_جسر_السلامية.md`
3. ✅ نسخ الملف إلى `references/منهجيات/`
4. ✅ تحديث `index.md` بسطر جديد
5. ✅ إبلاغك بملخص ما تم استخراجه

## ماذا تحتوي بطاقة المرجع؟

كل ملف مرجعي يُنشأ له بطاقة في مجلد `cards/` بهذا الشكل:

```markdown
# بطاقة مرجع: منهجية إنشاء جسر السلامية

- **الملف الأصلي:** منهجية انجاز الأعمال.docx
- **المسار:** references/منهجيات/منهجية_جسر_السلامية.docx
- **التصنيف:** منهجية إنجاز أعمال — مشاريع إنشاء
- **تاريخ التحليل:** 2026-07-14

## الهيكل المستخرج

### ترتيب الأقسام:
1. مقدمة عن المشروع
2. بيانات الجهة المالكة والمقاول
3. الموقع الجغرافي ووصف الموقع
4. نطاق العمل وبيان الأعمال
5. خطة التنفيذ المرحلية
6. الموارد البشرية والعمالة
7. المعدات والآليات
8. خطة الجودة وضبط المواد
9. إجراءات السلامة والصحة المهنية
10. الجدول الزمني الملخص
11. التوقيعات والاعتمادات

### التنسيقات:
- الخط: Traditional Arabic / 14pt
- المحاذاة: RTL
- العناوين: Bold / 16pt
- الرأس: شعار الشركة + اسم المشروع
- التذييل: رقم الصفحة + التاريخ

### ملاحظات المستخدم:
- هذا أفضل نموذج لمشاريع الإنشاء
- يجب الالتزام بنفس ترتيب الأقسام في كل منهجية جديدة
```

## كيف يستفيد النظام من المراجع؟

```
[طلبك] ──→ [الوكيل يقرأ index.md] ──→ [يجد المرجع المناسب]
                                              │
                                    [يقرأ بطاقة المرجع]
                                              │
                                    [يلتزم بنفس الهيكل والتنسيق]
                                              │
                                    [ينتج المستند الجديد]
```

---

## نصائح للاستخدام الأمثل

1. **اختر أفضل نموذج** — لا تضع كل ملفاتك، فقط الأنجح والأكثر قبولاً من الجهات الحكومية
2. **نموذج واحد لكل نوع يكفي** — مثلاً: منهجية واحدة للإنشاء + واحدة للصيانة + واحدة للتوريدات
3. **أضف ملاحظاتك** — الوكيل يسألك عن ملاحظات خاصة، استغل ذلك لتثبيت التفاصيل المهمة
4. **حدّث المراجع** — لو أنتجت نموذجاً أفضل لاحقاً، استبدل القديم

---

## البدء السريع

لبدء ضبط أول مرجع، اكتب:
```
ضبط مرجع
```
وسيرشدك الوكيل خطوة بخطوة.
