# 03 - مكتبة البرومبتات الديناميكية (Dynamic Prompt Library)

## الفكرة والمفهوم:
ربط ملف `مكتبة الأوامر.xlsx` ببيئة العمل برمجياً، بحيث يقوم النظام بالبحث الدلالي التلقائي وجلب البرومبت المخصص وحقنه في ذاكرة نموذج المحادثة فور كتابة المستخدم لكلمات مفتاحية معينة.

## الهيكل المقترح للبناء:
- `core/`: كود قراءة وتصفية ملف الإكسل.
- `templates/`: قوالب البرومبتات وهياكل الإدخال.
- `README.md`: معايير البحث الدلالي والتعبئة التلقائية.
